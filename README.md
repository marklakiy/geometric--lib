# Geometric Formulas Library

Репозиторий содержит справочник базовых геометрических формул для нахождения периметра и площади.

## Краткий перечень формул
### Area (Площадь)
- **Circle**: `S = πR²`
- **Rectangle**: `S = ab`
- **Square**: `S = a²`

### Perimeter (Периметр)
- **Circle**: `P = 2πR`
- **Rectangle**: `P = 2a + 2b`
- **Square**: `P = 4a`
