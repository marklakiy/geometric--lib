# Подробная документация геометрических формул

## Общее описание решения
Этот проект представляет собой справочник основных геометрических формул для быстрого расчета площади (**Area**) и периметра (**Perimeter**) фигур.

## Описание формул с примерами применения

### 1. Площадь круга (Circle Area)
* **Формула**: `S = πR²`
* **Описание**: Умножение квадрата радиуса на число Пи (приблизительно 3.14).
* **Пример расчета**: При радиусе R = 3, площадь будет: `S = 3.14 * 3² = 28.26`

### 2. Площадь прямоугольника (Rectangle Area)
* **Формула**: `S = ab`
* **Описание**: Произведение двух смежных сторон фигуры.
* **Пример расчета**: При сторонах a = 4 и b = 5, площадь будет: `S = 4 * 5 = 20`

### 3. Периметр прямоугольника (Rectangle Perimeter)
* **Формула**: `P = 2a + 2b`
* **Описание**: Удвоенная сумма двух смежных сторон прямоугольника.
* **Пример расчета**: При сторонах a = 4 и b = 5, периметр равен: `P = 2*4 + 2*5 = 18`
